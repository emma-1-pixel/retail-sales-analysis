# retail-sales-analysis
##Data Cleaning
Checked 9,994 rows: no missing values in Sales, Profit or Postal Code, no duplicate Row IDs, and consistent text in Region, Category and Segment.
## Findings
Tables, Bookcases and Supplies were unprofitable. Tables alone lost $17.7K (margin -8.6%) despite $207K in sales, while Copiers earned the highest profit ($55.6K, 37.2% margin).
